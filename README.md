# 制县等级 · 国内版（地级）

静态 HTML 旅行足迹地图：地级行政区粒度，缩放后从省粗粒度切到市细粒度。

## 本地打开

不要直接双击 `index.html`（`file://` 下无法加载 GeoJSON）。在项目目录运行：

```bash
python3 -m http.server 8080
```

浏览器打开 <http://localhost:8080>。

或：

```bash
npx --yes serve .
```

## 使用

- **电脑**：滚轮缩放、拖拽平移、点击区域打分  
- **手机**：双指缩放；放大后可点选地级单位  
- **低缩放**：省色 = 省内最高分，标签为 `去过/总数`；点击省会放大  
- **高缩放**：按市打分（0–5）  
- **生成图片**：导出当前会话结果为 PNG（不保存到浏览器，刷新即清空）  
- **分享**：只分享本站链接即可，不会带上个人足迹  

## 重建地图数据

```bash
node 工具/构建地图数据.mjs
node 工具/校验数据.mjs
```

## 计分自测

```bash
node 工具/计分自测.mjs
```
