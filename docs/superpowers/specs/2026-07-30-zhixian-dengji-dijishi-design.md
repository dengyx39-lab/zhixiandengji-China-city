# 制县等级 · 国内版（地级）设计说明

日期：2026-07-30  
状态：待用户审阅  
参考：[制县等级中国版](https://miklcct.github.io/zhixian-dengji-zhongguo-ban/)（省级粒度）

## 1. 目标

做一个可在浏览器打开的静态 HTML 旅行足迹地图：单位细到地级行政区，支持缩放后从「省粗粒度」切到「市细粒度」，按深度打分并导出图片。不持久化、不分享个人数据。

## 2. 范围

### 2.1 可打分单位

- 大陆：全部地级行政区（地级市、地区、自治州、盟）
- 直辖市：北京、天津、上海、重庆各 1 个单位（整块，不拆区）
- 台湾：拆到县市
- 香港、澳门：各 1 个单位

单位总数记为 `N`。地图多边形数量必须与可打分单位数一致（实现时用清单交叉校验）。

### 2.2 明确不做

- 不写入 `localStorage` / `IndexedDB` / Cookie（进度）
- 不把个人足迹编进分享 URL；分享链接永远是空白原版
- 不做账号、后端、排行榜
- 不做县级（大陆）更细粒度

## 3. 计分与图例

| 分 | 含义 | 颜色 |
|---:|---|---|
| 0 | 没去过 | 浅灰 / 白 |
| 1 | 玩过 | 绿 |
| 2 | 睡过 | 蓝 |
| 3 | 居住 · 半年内 | 黄 |
| 4 | 居住 · 半年–2年 | 橙 |
| 5 | 居住 · 2年以上 | 红 |

- **总分** = 各单位分数之和  
- **满分** = `N × 5`  
- 顶部展示：`当前分 / 满分`  
- 「去过」判定：分数 ≥ 1  

## 4. 交互

### 4.1 缩放与图层

- 桌面：滚轮缩放、拖拽平移、单击点选  
- 手机：双指捏合、单指拖拽、轻点点选  
- **低缩放（省粗粒度）**
  - 显示省界
  - 省颜色 = 省内所属单位的最高分
  - 省标签：`去过市数 / 省内总市数`
  - 点击省：放大并聚焦该省（不直接给全省统一打分）
- **高缩放（市细粒度）**
  - 超过固定缩放阈值后切换为市界
  - 各市独立着色、独立点选
  - 标签过密时仅悬停/选中显示市名
- 提供「重置视野」回到全国总览

### 4.2 打分面板

点击市（细粒度）弹出 0–5 档位表；选中后立即上色并刷新总分与相关省汇总。

### 4.3 导出与分享

- 「生成图片」：将会话内当前地图 + 标题总分 + 图例导出为 PNG  
- 分享：仅分享站点原始链接；打开后始终从空白开始  

## 5. 技术结构

风格对齐参考站：静态文件、少构建、打开即用。

```
国内版（地级市）/
├── index.html
├── 样式.css
├── 脚本.js
├── 数据/
│   ├── 省.geojson
│   ├── 市.geojson
│   └── 清单.json
└── 库/
    ├── leaflet/
    └── html2canvas/
```

### 5.1 运行时数据流

1. 加载 `省.geojson` / `市.geojson` / `清单.json`  
2. 内存中维护 `分数表[单位id] = 0..5`（默认 0）  
3. Leaflet 渲染两套 GeoJSON 图层，按缩放级别显隐  
4. 上色与省汇总均由 `分数表` 派生，不落盘  
5. 关闭或刷新页面后状态清空  

### 5.2 数据要求

- `清单.json`：至少包含 `id`、`名称`、`所属省`（直辖市/港澳台用约定所属键）  
- `市.geojson` feature 的属性 `id` 与清单一致  
- 构建或启动时校验：清单条数 = 市图层 feature 数；缺失/多余则在控制台报错  

数据来源：公开行政区划 GeoJSON（大陆地级 + 直辖市整块 + 台湾县市 + 港澳），必要时离线裁剪/合并后放入 `数据/`。

### 5.3 依赖

- Leaflet：地图、缩放、点击  
- html2canvas（或同等方案）：导出 PNG  

优先本地 `库/`  vendoring，避免强依赖外网 CDN（可选 CDN 回退，但默认离线可开）。

## 6. UI 骨架

- 全屏地图为底  
- 浮层：标题「制县等级 · 国内版」、`当前分 / 满分`、图例 0–5、重置视野、生成图片  
- 点选弹层：单位名称 + 六档选择  

视觉以色块与图例为主，避免仪表盘式堆叠信息。

## 7. 错误处理与边界

- 地图数据加载失败：页面提示「数据加载失败」，不静默空白  
- 未知单位 id：忽略打分并 `console.warn`  
- 省内无市数据：该省不显示 `x/y` 或显示 `0/0` 并告警（实现时二选一，默认 `0/0` + warn）  
- 导出失败：提示重试，不影响已选分数（仍在内存）  

## 8. 验收标准

1. 手机可双指缩放；放大过阈值后由省层切到市层  
2. 电脑滚轮缩放 + 鼠标点选打分正常  
3. 省色 = 省内最高分；省标签为去过/总数  
4. 总分与满分计算正确（满分 = N×5）  
5. 刷新后分数清空；分享 URL 不含个人数据  
6. 会话内可导出含图例与总分的 PNG
